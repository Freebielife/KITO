# KITO Observatory

Бесплатная RU/EN панель для freebie.socool.ton. Публичные источники, без сервера и ключей.

## Скачать для Resistance Tools

[Скачать index.html](https://raw.githubusercontent.com/Freebielife/KITO/main/index.html). Загрузите его как корневой файл статического сайта. Вся разметка, оформление, скрипт и резервный снимок уже внутри. При загрузке через GitHub с телефона используйте кнопку Download raw file.

## Данные

- Мастер KITO: `EQCSLLVQ8qdhEqZUKaiKU7F6sVfnNPmQ4FsCpCo8olo795LP`
- Пул DeDust: `EQDBJK9IVV2MLjHxpsSj4DOuybmwnO0QjUTIoQVpdfgXb4qQ`
- Сделки — подтверждённые события swap пула. График показывает KITO за 1 GRAM. Продавцы ранжируются по объёму проданных KITO за 1, 7 и 30 дней.
- Сжигания — успешные уведомления burn, принятые самим мастером. Доли держателей считаются от текущего предложения, на странице топ-20 адресов.
- Сборщик пополняет годовой архив постепенно. При неполной истории график и рейтинг показывают границу охвата. Интервалы без сделок не содержат наблюдений цены.
- GitHub Actions запускает сбор в 17 минут каждого второго часа UTC. Каждый источник сохраняет свою отметку времени. При ошибке остаётся его предыдущий снимок.
- Клиент сначала использует встроенные данные, затем запрашивает GitHub Raw; GitHub Pages служит запасным адресом, если включён для репозитория. Проверка при открытии, при возврате на вкладку и каждые 10 минут.

## Разработка

Python 3.10+, без сторонних зависимостей. Из корня запустите `python3 collect.py`, затем `python3 build.py` и `python3 verify.py`. Исходники страницы находятся в web/. Ручной запуск сбора — Actions → Refresh KITO data → Run workflow. Откройте index.html для локального просмотра. Код на GitHub и публикация сайта через Resistance Tools — отдельные шаги.
